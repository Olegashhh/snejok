## 4. Движок снега (`WinterDesktop.SnowEngine`)

- [x] Детерминированный ГПСЧ (`SnowRandom`) и пул частиц с жёстким лимитом.
- [x] Спавн по площади мониторов с учётом per-monitor интенсивности.
- [x] Падение, ветер по силе/углу, турбулентность, боковой разброс, покачивание.
- [x] Четыре формы снежинок, крупные снежинки, прозрачность, размер.
- [x] Два слоя глубины: фон (ложится на верхние кромки) и передний план
      (ложится на подоконники).
- [x] Сугробы-heightfield: до 512 сэмплов, гауссово осаждение, насыщение,
      максимальная толщина, глобальный бюджет массы.
- [x] Сглаживание сугроба с сохранением массы и ограничение крутизны (угол откоса).
- [x] Разная высота сугробов: коэффициент 0.85…1.0 на кромку и медленный профиль
      вдоль кромки (три волны ≈400–3100 px); общий лимит толщины не превышается.
- [x] Дедупликация кромок: панель задач и подоконник на низу рабочей области
      не создают второй сугроб на той же линии.
- [x] Рендер сугробов единым сглаженным контуром (`FillGeometry`), без полос
      и двойного наложения полупрозрачной кисти.
- [x] Рыхлый снег: размеры снежинок со смещением к мелким, прозрачность 0.42…1.
- [x] Коллизии с кромками окон; пропуск кромок за пределами рабочего стола.
- [x] Перемещение кромок вместе с окном, ссыпание снега при закрытии окна.
- [x] Видимость кромки с учётом перекрытия окнами выше по z-order.
- [x] Низ рабочей области: окна, уходящие под панель задач, вычитаются из видимых
      интервалов, чтобы снег не висел над их содержимым; окно, стоящее ровно на
      линии, сохраняет кромку.
- [x] Варежка: эрозия сугроба с «брызгами».
- [x] Лопата: очистка круга с брызгами и снежной пылью (пыль видна даже там, где
      под курсором нет сугроба).
- [x] «След» курсора: частицы увлекаются движением мыши.
- [x] `WarmStart`: мгновенное заполнение сцены при старте.
- [x] Очистка всего снега / монитора / окна; `FindLedgeAt` для очистки под курсором.
- [x] Точный пересчёт массы после частичной очистки.
- [x] Снежок: лепка из сугроба через `TakeSnow`, удержание у курсора, бросок по
      скорости курсора, гравитация и ветер, `splat` о кромку (депозит + брызги)
      или тело окна (только брызги), лимит 32 шара. На тонких полосах снег
      подгребается с широкой полосы вдоль кромки, поэтому шар лепится и там; если
      снега нет совсем, показывается снежная пыль.
- [x] Снеговик: три нажатия по сугробу добавляют шары 1–3, фигура привязана к
      ключу кромки, основание следует за кромкой; лимит 24 фигуры.
- [x] Экспорт/восстановление снеговиков, событие `SnowmenChanged`, очистка фигур
      вместе с очисткой снега/монитора/окна.
- [x] Гирлянды: нить по верхней кромке окна (провод на 2,2 DIP ниже кромки,
      лампочки свисают в сторону окна), пересборка только при смене сцены/настроек.
- [x] Учёт перекрытий: `ComputeGarlandSpans` вычитает окна выше по z-order той же
      операцией `SubtractFrom`, что и видимость сугробов; разрывы не соединяются.
- [x] Палитры «Зимняя», «Праздничная», «Тёплая», «Карамельная» и режимы
      «Мерцание», «Переливы», «Бегущий огонь», «Ровный свет» (`GarlandTiming`).
- [x] Жёсткий лимит `MaxGarlandBulbs = 4096`; панель задач, оболочка и кромки
      за пределами виртуального стола пропускаются.
- [x] 24+ юнит-теста движка (включая off-screen кромки, очистку по монитору и
      видимость низа рабочей области), 12 тестов снежков/снеговиков и 9 тестов
      гирлянд.

## 14. Известные проблемы, требующие внимания

- [~] Контекстное меню трея в Win11 не удалось проверить автоматизацией;
      требуется ручная проверка.
- [~] `FullscreenDetector` не срабатывает на borderless-окно, если оно не совпадает
      с монитором ровно; см. `KNOWN_LIMITATIONS.md`.
- [~] `StartMinimized` в локальном `settings.json` тестовой машины выставлен в
      `false` во время приёмки; значение по умолчанию — `true`.
- [~] Снеговики восстанавливаются один раз за запуск и не переживают очистку снега
      до перезапуска; снежок не сталкивается с фигурами и телом окна
      (см. `KNOWN_LIMITATIONS.md`).
