# Winter Desktop

Бесплатное приложение для Windows, которое рисует интерактивный снегопад поверх
рабочего стола и открытых окон: снежинки падают, ветер меняет их траекторию, а на
верхних кромках окон и на панели задач копятся сугробы. Сугробы можно смахивать
варежкой или убирать лопатой.

Приложение работает полностью локально: без интернета, учётной записи, телеметрии
и чтения содержимого чужих окон. Используется только геометрия окон.

> Текущее состояние: **MVP (этапы 1–2 ТЗ) готов**, из этапа 3 реализованы снежки,
> снеговики и гирлянды. Снегоуборщик, пользовательские изображения и декоративные
> сцены запланированы — см. `docs/ROADMAP.md`.

## Требования

- Windows 10 64-bit или Windows 11 (проверено на Windows 11).
- .NET Desktop Runtime 8 x64 — для запуска готовой сборки.
- .NET SDK 8.0 — для сборки из исходников.
- Видеодрайвер с поддержкой Direct3D 11 и DirectComposition. Если дискретный/встроенный
  GPU недоступен, приложение автоматически переходит на программный WARP-рендер.

## Сборка

```powershell
cd WinterDesktop
dotnet build WinterDesktop.sln -c Debug
```

Сборка без предупреждений: nullable включён, предупреждения nullable считаются
ошибками (`Directory.Build.props`).

Release-сборка:

```powershell
dotnet publish src\WinterDesktop.App\WinterDesktop.App.csproj -c Release -r win-x64 --self-contained false
```

## Запуск

```powershell
.\src\WinterDesktop.App\bin\Debug\net8.0-windows\win-x64\WinterDesktop.exe
```

- Обычный запуск открывает окно настроек; при `StartMinimized = true` (по умолчанию)
  приложение уходит в трей. Первый запуск всегда показывает окно.
- `WinterDesktop.exe --tray` — принудительно запустить свёрнутым в трей.
- Значок в области уведомлений: одиночный клик открывает настройки, меню — быстрое
  включение/выключение снега, режим взаимодействия, очистка и выход.

Повторный запуск второго экземпляра блокируется: приложение сообщает, что уже
работает, и завершает новый процесс.

## Управление

| Действие | Где |
|---|---|
| Включить/выключить снег | вкладка «Главная», трей |
| Режим взаимодействия (включить/выключить) | «Главная», трей, Ctrl+Alt+W (глобально) |
| Пауза/продолжить эффекты | «Главная», трей |
| Режим и интенсивность | «Главная» |
| Ветер, турбулентность, формы | «Снегопад» |
| Где копится снег и максимальная толщина | «Накопление» |
| Гирлянды: включение, палитра, режим, скорость, шаг, размер, свечение | «Гирлянды», трей |
| Варежка, лопата, снежок и снеговик | «Инструменты» |
| Отключение мониторов | «Мониторы» |
| FPS, профиль, автопауза, батарея | «Производительность» |
| Автозапуск, экспорт/импорт, сброс, логи | «Общие» |

## Файлы и данные

| Что | Путь |
|---|---|
| Настройки | `%LOCALAPPDATA%\WinterDesktop\settings.json` |
| Резервная копия | `%LOCALAPPDATA%\WinterDesktop\settings.json.bak` |
| Копия повреждённого файла | `%LOCALAPPDATA%\WinterDesktop\settings.corrupt-YYYYMMDD-HHmmss.json` |
| Логи | `%LOCALAPPDATA%\WinterDesktop\logs\app-YYYYMMDD.log` (ротация, 7 дней) |

Настройки сохраняются автоматически с задержкой ~0,7 с после последнего изменения.
Запись атомарная: временный файл → `File.Replace` с резервной копией. Если JSON
повреждён, приложение стартует с настройками по умолчанию, сохраняет копию
повреждённого файла и пишет предупреждение в лог.

## Тесты

```powershell
dotnet test tests\WinterDesktop.Core.Tests
dotnet test tests\WinterDesktop.Settings.Tests
```

Сейчас: **76 тестов ядра/снега/настроек + 13 тестов хранилища = 89**, все проходят.
Тесты не требуют GPU, окон и реального времени: симуляция использует
детерминированный ГПСЧ и явный шаг времени.

## Приватность

- Нет сетевых запросов и телеметрии.
- Не читаются заголовки, текст и изображения окон — только прямоугольники,
  видимость и z-order.
- Нет глобального хука мыши: позиция курсора опрашивается раз в кадр.
- Единственная глобальная горячая клавиша — Ctrl+Alt+W; она регистрируется через
  `RegisterHotKey`, без хуков клавиатуры.
- Нет скрытых служб и драйверов.
